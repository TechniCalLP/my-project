## Max-width Guidelines

Use these max-width values for consistency:

- **max-w-2xl (672px)**: Form-heavy pages
  - Join Page (code input form)
  - Settings Page (password form)

- **max-w-5xl (1024px)**: Content-heavy pages  
  - Activities Page (grid of cards)
  - History Page (list of activities)

- **max-w-7xl (1280px)**: Dashboard only
  - Already implemented correctly

All pages must use `mx-auto` to center horizontally.
