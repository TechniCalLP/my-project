# Improve Admin Dashboard - Separate Action Column

## Overview

Split the "ผู้เข้าร่วม" column into two columns:
1. "ผู้เข้าร่วม" - Show participant count only
2. "จัดการ" - Show action buttons (ดูรายละเอียด, แก้ไข, ลบ)

## File to Update

File: `components/admin/recent-activities.tsx`

## Complete Replacement

Replace the entire file with:

## Key Changes

### New Column Structure:

1. **ชื่อกิจกรรม** - Activity name + year/semester
2. **ประเภท** - Category badge
3. **สถานะ** - Status badge (เปิดรับสมัคร/ปิดแล้ว)
4. **ผู้เข้าร่วม** - Participant count with icon
5. **จัดการ** - Action buttons (NEW!)

### Action Buttons:

1. **ดูรายละเอียด** (View)
   - Icon: Eye
   - Color: Primary (Navy)
   - Link: `/admin/activities/{id}/participants`

2. **แก้ไข** (Edit)
   - Icon: Edit
   - Color: Warning (Orange)
   - Link: `/admin/activities/{id}/edit`

3. **ลบ** (Delete)
   - Icon: Trash2
   - Color: Secondary (Red)
   - Action: Confirmation dialog + delete

### Styling:

✅ Buttons in a row with gap
✅ Icons + text labels
✅ Hover effects (color change)
✅ Outline variant
✅ Small size (sm)
✅ Color-coded by action type
✅ Responsive spacing

### Button Colors:

- **ดูรายละเอียด**: Navy (Primary)
- **แก้ไข**: Orange (Warning)
- **ลบ**: Red (Secondary)

All buttons have:
- Outline style by default
- Filled background on hover
- White text on hover
- Icon + text
