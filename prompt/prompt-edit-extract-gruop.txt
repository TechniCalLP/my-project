🔧 Logic - วิธีแยก Group
Pattern ที่ใช้:
[ชื่อแผนก] [กลุ่ม?] [ปี] (ประเภท.ปี(GROUP_CODE))

ตัวอย่าง:
1. เทคโนโลยีสารสนเทศ/1 2566 (ช.66(IT1))
   ├─ Group (Bracketed): IT1 ← ใช้นี่!
   
2. ช่างยนต์ กลุ่ม A1 2566 (ช.66(AU1))
   ├─ Group (Text): A1 ← ใช้นี่!
   └─ Program Code (Bracketed): AU1 ← ถ้า A1 ไม่เจอ
ลำดับความสำคัญ (Priority):
1️⃣ ค้นหา "กลุ่ม [A-Z0-9]+" 
   └─ เช่น "กลุ่ม A1" → Extract "A1"

2️⃣ ค้นหาใน Bracketed "(ประเภท.ปี([A-Z0-9]+))"
   └─ เช่น (ช.66(AU1)) → Extract "AU1"
   
3️⃣ ค้นหา "/[0-9]" 
   └─ เช่น "/1" → อาจเป็น Group "1"

💻 Pseudocode
javascriptfunction extractGroupFromDepartment(departmentName) {
  // Input: "ช่างยนต์ กลุ่ม A1 2566 (ช.66(AU1))"
  
  // 1️⃣ ลองหา "กลุ่ม [A-Z0-9]+"
  const groupMatch = departmentName.match(/กลุ่ม\s+([A-Z0-9]+)/i);
  if (groupMatch) {
    return groupMatch[1]; // "A1"
  }
  
  // 2️⃣ ลองหา Bracketed "(ประเภท.ปี([A-Z0-9]+))"
  const bracketMatch = departmentName.match(/\(([ชส])\.(\d{2})\(([A-Z0-9]+)\)\)/);
  if (bracketMatch) {
    return bracketMatch[3]; // "AU1"
  }
  
  // 3️⃣ ลองหา "/[0-9]" ที่อยู่หลัง department name
  const slashMatch = departmentName.match(/\/(\d+)\s+\d{4}/);
  if (slashMatch) {
    return slashMatch[1]; // "1"
  }
  
  // 4️⃣ ไม่เจอ group → return null
  return null; // "No group found"
}

javascript// Validate Group
function isValidGroup(group) {
  if (!group) return true; // Optional field
  
  // Group should be alphanumeric + Thai chars
  // Pattern: A1, AU1, IT1, 1, 2, etc.
  const pattern = /^[A-Z0-9ก-ฮ]+$/i;
  return pattern.test(group);
}

function extractGroup(departmentName: string): string | null {
  // Use logic from above
  const groupMatch = departmentName.match(/กลุ่ม\s+([A-Z0-9]+)/i);
  if (groupMatch) return groupMatch[1];
