🔧 PROMPT - Fix Student Year Detection Logic
Project Path

Problem
Student import auto-detects year from department, but needs to handle repeat/special cases:
Example:
- StudentID: 6620901020
- Department: "เทคโนโลยีสารสนเทศ.../1 2564 (ช.64(IT1))"
- Auto-detect: 2568 - 2564 + 1 = ปวช 5 ❌
- Should be: ปวช 3 (repeat year)

Solution
Add hard-coded rules for year detection:
Rule:
- If admission year <= 2564: Set to max (ปวช 3 or ปวส 2)
- If admission year = 2565: ปวช 3
- If admission year = 2566: ปวช 2
- If admission year = 2567: ปวช 1
- If admission year = 2568+: ปวช 1

Implementation
Step 1: Find Student Import API
File: src/app/api/admin/import/students/route.ts
Look for the student import endpoint where year is calculated.
Step 2: Update Year Detection Logic
Replace or add this function:
typescriptfunction detectStudentYear(
  admissionYear: number | null,
  curriculumType: string | null
): number | null {
  if (!admissionYear || !curriculumType) {
    return null;
  }

  // Hard-coded rules for year detection
  // Handle repeat/special years
  
  if (admissionYear <= 2564) {
    // Repeat year: students who entered before 2564
    // Now at max level: ปวช 3 or ปวส 2
    return curriculumType === 'ช' ? 3 : 2;
  }

  if (admissionYear === 2565) {
    return 3; // ปวช 3
  }

  if (admissionYear === 2566) {
    return 2; // ปวช 2 or ปวส 1
  }

  if (admissionYear === 2567) {
    return 1; // ปวช 1
  }

  // For 2568 onwards
  return 1;
}

Find where you calculate current year from department:

Step 4: Extract Admission Year & Type
Make sure you're extracting these correctly from department:
typescriptfunction extractYearAndType(department: string) {
  // Extract year (2566, 2567, 2564, etc.)
  const yearMatch = department.match(/(\d{4})/);
  const admissionYear = yearMatch ? parseInt(yearMatch[1]) : null;

  // Extract type: ช (ปวช) or ส (ปวส)
  const typeMatch = department.match(/\(([ช|ส])\./);
  const curriculumType = typeMatch ? typeMatch[1] : null;

  return { admissionYear, curriculumType };
}
