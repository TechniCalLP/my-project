## Alternative: Conditional Rendering with Fallback

If you want automatic fallback to Shield icon on error:

```typescript
{/* Logo with fallback */}

  
    <Image 
      src="/logo-college.png" 
      alt="วิทยาลัยเทคนิคลำปาง"
      width={128}
      height={128}
      className="object-cover"
      priority
      unoptimized
      onError={(e) => {
        // Hide image and show shield icon on error
        const target = e.currentTarget as HTMLImageElement;
        target.style.display = 'none';
        const parent = target.parentElement;
        if (parent) {
          parent.innerHTML = '';
        }
      }}
    />
  

```
