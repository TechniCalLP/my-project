## Files to Update

### 1. Tailwind Config

File: `tailwind.config.ts`

```typescript
import type { Config } from "tailwindcss"

const config: Config = {
  content: [
    "./src/pages/**/*.{js,ts,jsx,tsx,mdx}",
    "./src/components/**/*.{js,ts,jsx,tsx,mdx}",
    "./src/app/**/*.{js,ts,jsx,tsx,mdx}",
  ],
  theme: {
    extend: {
      colors: {
        // Primary (Navy Blue)
        primary: {
          50: '#F0F1FC',
          100: '#E0E2F9',
          200: '#C1C5F3',
          300: '#A2A8ED',
          400: '#676FBF',
          500: '#2E3192',
          600: '#252775',
          700: '#1C1D58',
          800: '#14143B',
          900: '#0A0A1E',
          DEFAULT: '#2E3192',
        },
        // Secondary (Red)
        secondary: {
          50: '#FEF2F3',
          100: '#FCE5E7',
          200: '#F9CBCF',
          300: '#F5A1A9',
          400: '#E56773',
          500: '#C52833',
          600: '#9E2029',
          700: '#77181F',
          800: '#4F1014',
          900: '#28080A',
          DEFAULT: '#C52833',
        },
        // Semantic Colors
        success: '#2E9283',
        warning: '#F59E0B',
        danger: '#C52833',
        info: '#2E3192',
      },
    },
  },
  plugins: [],
}

export default config
```

### 3. Component Updates

Update all components to use new colors:

#### Buttons
```typescript
// Primary button: Navy background
className="bg-primary hover:bg-primary-600 text-white"

// Secondary button: Red background  
className="bg-secondary hover:bg-secondary-600 text-white"

// Outline button: Navy border
className="border-2 border-primary text-primary hover:bg-primary-50"
```

#### Badges
```typescript
// Category badges - use brand colors
const categoryColors = {
  ACADEMIC: 'bg-primary-100 text-primary-700 border-primary-200',
```

#### Status Indicators
```typescript

// Success: Teal
```

#### Navigation

#### Progress Hero (Dashboard)

- Secondary buttons
- Alerts/warnings
- Accent highlights
- Important badges
- Gradients (paired with navy)

**Success (Teal):**
- Success messages
- Completed states
- Positive indicators

**Warning (Orange):**
- Warning messages
- Pending states
